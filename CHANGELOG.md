# Зміни

## 0.1.4

Українська локалізація WHITE ALBUM: Memories like Falling Snow — тестова версія 0.1.4.

Пакет оновлено до поточного стану тестової копії:
- виправлено край таблички імені та перекриття сусіднім написом «Різдво»;
- уточнено межі написів тем розмови й кнопок меню;
- вирівняно шрифт основних пунктів меню, пункт налаштувань називається «Опції»;
- включено поточні сценарії, шрифти, інтерфейс та EXE.

Встановлення й відкат перевірені на окремій копії гри. Останні графічні зміни ще потребують підтвердження безпосередньо в грі; це попередній реліз.

Завантажуйте `WHITE_ALBUM_UA_0.1.4.zip`, а не архіви «Source code». Інструкція встановлення — у README та всередині ZIP. Для оновлення старої версії спочатку запустіть її `restore.ps1`.
