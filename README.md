# WHITE ALBUM — українська локалізація

Неофіційний український переклад **WHITE ALBUM: Memories like Falling Snow** для Steam (App ID 2432110).

**Поточна версія: 0.1.4, тестовий реліз.** Пакет містить українські сценарії, інтерфейс, шрифти та останні виправлення меню й табличок імен. Повний прохід гри та екранна перевірка всіх сцен ще не завершені.

[Завантажити ZIP 0.1.4](https://github.com/ZandERIncUB/WHITE-ALBUM-UA/releases/download/v0.1.4/WHITE_ALBUM_UA_0.1.4.zip) · [Усі релізи](https://github.com/ZandERIncUB/WHITE-ALBUM-UA/releases) · [Повідомити про проблему](https://github.com/ZandERIncUB/WHITE-ALBUM-UA/issues)

## Встановлення

Потрібна встановлена Steam-версія гри 1.01 із файлами, що відповідають контрольним сумам пакета.

1. Закрийте гру.
2. Завантажте ZIP із розділу Releases та розпакуйте його в окрему папку. Архіви GitHub «Source code» не містять файлів локалізації.
3. Відкрийте PowerShell у розпакованій папці та виконайте, підставивши свій шлях:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -GamePath "D:\SteamLibrary\steamapps\common\WHITE ALBUM"
   ```

Інсталятор перевіряє файли та зберігає оригінали в `.white-album-ua-backup/0.1.4` усередині папки гри. Права адміністратора потрібні лише якщо Windows відмовляє у записі.

## Оновлення та видалення

Для оновлення старої локалізації спочатку виконайте `restore.ps1` **зі старого пакета**, потім установіть нову версію. Для видалення поточної версії закрийте гру та виконайте з її розпакованого пакета:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\restore.ps1 -GamePath "D:\SteamLibrary\steamapps\common\WHITE ALBUM"
```

Збереження гри не змінюються. Резервні копії оригіналів залишаються після відкату. Не видаляйте їх до відновлення.

## Що перевірено

- Усі 16 файлів пакета відповідають поточній тестовій копії.
- Встановлення та відкат перевірені на окремій копії повнорозмірних файлів гри.
- Перевірені склад ZIP і SHA-256 файлів.
- Останні зміни меню й табличок перевірені у зібраних текстурах; екранне підтвердження після перезапуску гри ще очікується.

У релізі є файл `.sha256` для перевірки ZIP. Для звіту про помилку вкажіть версію патча, сцену або пункт меню й додайте скриншот.
